이 앱은 Claude를 통해 사업 검증·리서치·슬라이드 작성·CEO 검토를 자동화합니다. 본인의 Claude 계정이 필요해요. 두 가지 방법 중 하나를 선택하세요.

월정액 추천

Claude Code CLI가 설치돼 있고 본인 계정으로 로그인한 상태라면 그 인증을 그대로 씁니다. 월정액 한도 안에서 무제한.

종량제
Anthropic API Key
Anthropic 콘솔에서 발급받은 API key를 입력합니다. 호출 1회당 요금이 부과돼요 (Pro/Max 구독과 별개).
언제든 사용 가능 per-token billing

⚡ Claude Code 인증 사용

🔑 API Key 입력

Anthropic Console에서 API key를 만들고 sk-ant-...로 시작하는 문자열을 붙여넣으세요. 이 키는 이 PC의 로컬 설정 파일(%APPDATA%\Biz Plan Agent\config.json)에만 저장됩니다. 외부 서버로 전송되지 않습니다.

이 앱은 키를 외부로 전송하지 않습니다. 모든 Claude 호출은 사용자 PC ↔ Anthropic 간 직접 통신입니다.
