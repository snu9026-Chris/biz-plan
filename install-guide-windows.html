STEP 1

Windows 설치 01
  1. code.visualstudio.com 접속 → Download for Windows 클릭.
  2. 다운로드 폴더에서 VSCodeUserSetup-x64-x.x.x.exe 더블클릭.
  3. 설치 마법사 — "PATH에 추가" 옵션은 ✅ 체크하는 게 편함.
  4. 설치 완료 → 자동 실행되면 그대로 두기. 한국어 패치 알림 뜨면 한 번에 적용.
팁 Windows 11에서는 winget install Microsoft.VisualStudioCode 한 줄로도 설치됩니다. PowerShell 관리자 권한으로.

Install · 07 🪟 Windows

STEP 3

Anthropic 인증 — 둘 중 하나.

이 확장은 Claude API를 호출하기 때문에 — 인증이 별도 필요합니다.
방법은 두 가지. 본인 상황에 맞는 거 골라서.

A. API 키 방식

가장 간단. 사용한 만큼 과금.
① console.anthropic.com에서 키 발급
② VSCode에서 Ctrl+, 눌러 설정 열기
③ 검색창에 "biz plan" 입력
④ Anthropic Api Key에 키 붙여넣기
⑤ Use Claude Code Auth 체크 해제

B. Claude Pro 구독

Pro/Max 구독자면 추가 비용 없음.
① Claude Code CLI 설치
② PowerShell에서 claude login 실행 → 브라우저로 로그인
③ VSCode 설정에서 Use Claude Code Auth ✅ 유지 (기본값)
④ 끝 — 추가 입력 없음
권장 처음이면 A. API 키 방식이 빠릅니다. 키 발급 후 한 번만 붙여넣으면 끝. B 방식은 Claude Code CLI 설치가 별도로 필요해서 단계가 더 많음.
