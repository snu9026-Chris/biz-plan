Install · 02 🍎 macOS · 🛰 Antigravity

잠깐, 그 전에

Antigravity는 — VSCode 기반.

Antigravity는 VSCode를 fork한 IDE입니다. 그래서
VSCode 확장(.vsix)이 그대로 작동합니다. 별도로 VSCode 깔 필요 없음.

✓ 그대로 됩니다

• 확장 패널 UI 동일
• 단축키 ⌘+⇧+X 동일
• VSIX에서 설치 메뉴 동일
• 액티비티 바 아이콘 동일

! 다를 수 있는 것

• Marketplace 검색은 안 될 수도
(MS가 fork에서 막아둠 — 우린 .vsix 직접 설치라 무관) • 좌측 아이콘 정렬 순서
(아이콘은 똑같이 생기지만 위치만)
✓ VSCode ✓ Antigravity ✓ Cursor ✓ Windsurf ✓ VSCodium

Install · 06 🍎 macOS · 🛰 Antigravity

STEP 4

Anthropic 인증 — 둘 중 하나.

이 확장은 Claude API를 호출하기 때문에 — 인증이 별도 필요합니다.
방법은 두 가지. 본인 상황에 맞는 거 골라서.

A. API 키 방식

가장 간단. 사용한 만큼 과금.
① console.anthropic.com에서 키 발급
② Antigravity에서 ⌘+, 눌러 설정 열기
③ 검색창에 "biz plan" 입력
④ Anthropic Api Key에 키 붙여넣기
⑤ Use Claude Code Auth 체크 해제

B. Claude Pro 구독

Pro/Max 구독자면 추가 비용 없음.
① Claude Code CLI 설치
② 터미널에서 claude login 실행 → 브라우저로 로그인
③ 설정에서 Use Claude Code Auth ✅ 유지 (기본값)
④ 끝 — 추가 입력 없음
권장 처음이면 A. API 키 방식이 빠릅니다. 키 발급 후 한 번만 붙여넣으면 끝. B 방식은 Claude Code CLI 설치가 별도로 필요해서 단계가 더 많음.

Install · 08 🍎 macOS · 🛰 Antigravity

막혔다면

흔한 문제 — 이렇게 푸세요.

대부분 — 이 셋 중 하나입니다.

🚫

🚀 아이콘 안 보임

Antigravity 한 번 재시작. 또는 액티비티 바 우클릭(⌃+클릭) → "Biz Plan Agent" 체크.

🔑

"No API key" 에러

Step 4를 다시. API 키 모드면 Use Claude Code Auth 체크 해제 확인.

⚠️

단축키가 안 먹어요

좌측 아이콘 직접 클릭. Antigravity가 키바인딩을 재정의했을 수도. 네모 4개 아이콘 누르면 됨.

그래도 안 되면 Antigravity 출력 패널을 확인하세요. ⌘+⇧+U 또는 메뉴 View → Output. 드롭다운에서 "Biz Plan Agent" 선택하면 에러 로그가 보입니다. 그 메시지를 그대로 공유하세요.
